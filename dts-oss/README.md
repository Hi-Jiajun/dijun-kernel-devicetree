# 开源 DTS 参考目录（Android 15 / Linux 6.6.30，非现行真机基线）

本目录 `6.6.30-android15-v/` 来自小米早期公开的 `dijun-v-oss` 源码树（base model `XiaoMi Franklin1 Basic`）。

> [!WARNING]
> **仅供玄戒 O1 宏定义、绑定头与节点语义参考，严禁当作 OS3（`6.6.118`）或 OS4（`6.18.21` / `6.18.32`）真机现行设备树使用。**
>
> - 该代树与现行真机设备树存在数十个节点增删及上百处属性差异（含电源、时钟、摄像头开关状态等）。
> - 当前 OS4.0.4.0 真机权威设备树源码请看 [`../dts-current/`](../dts-current/)（指向 [`../dts-reconstructed/6.18.21-os4.0.4.0/`](../dts-reconstructed/6.18.21-os4.0.4.0/)）。
